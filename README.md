Schaltet einen GPIO in Abhängigkeit eines NTCs.  
Das zweite Script misst zum Vergleich noch einen BME280 aus.  
Der Wert des NTCs wird durch fünf Messungen gemittelt.  
Auf der seriellen Konsole werden die Werte ausgegeben, z.B.:  

NTC Mittelwert: 2265  
1.00 °C  
Zu kalt  
Heizung ist an  

NTC:        100 kOhm bei 25 °C  
Widerstand: 330 kOhm

Bzw.:

Temperatur: 19.52 °C  
Luftdruck: 985.66 hPa  
Luftfeuchtigkeit: 55.40 %  
  
NTC Mittelwert: 2676  
Geschätzte Temperatur: 19.00 °C  
Warm genug  
Heizung ist aus
